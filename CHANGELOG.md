# Changelog

Notable changes are recorded here. Versions follow Semantic Versioning for the packaged project; the initial standalone application existed before this repository.

## 0.1.0 — 2026-11-09

### Added

- Computational Kitchen landing page and Pizza Computational Lab directory.
- Existing standalone bilingual pizza planner, recipe engine, flour catalogue, documented formulas, exploratory fermentation model, local PDF checklist and calendar export.
- English and Italian README files, custom SVG banner, contribution/security guidance and technical documentation.
- Twelve portable regression suites, including a reference recipe fixture, and a dependency-free test/build/preview toolchain.
- GitHub Actions CI for Node 22/24 and a single-artifact Pages build/deployment workflow with a configuration preflight.
- Issue forms, a pull request template and Dependabot proposals for Action updates.
- GPLv3 project license and separately preserved OFL font attribution.

### Changed

- Product title and hero renamed from Pizza Lab Playground to Pizza Computational Lab for this distribution; recipe engine unchanged.
- Replaced the repository's initial GPLv2 placeholder with the previously requested GPLv3 license for the imported project.

This version label documents the package; a GitHub Release is not created automatically.
